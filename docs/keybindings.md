# Key bindings

## Home Screen

| Key        | Action                               |
| ---------- | ------------------------------------ |
| ctrl+o     | Choose directory/folder              |
| ctrl+enter | Manage the selected directory/folder |
| q or Esc   | Quit                                 |

## Image Screen

### Main Page

| Key      | Action              |
| -------- | ------------------- |
| l        | Next photo          |
| h        | Previous photo      |
| j        | Mark for delete     |
| k        | Mark for keep       |
| c        | Mark for clear      |
| m        | Mark for review     |
| q or Esc | Quit to Home screen |

### Summary Page

| Key      | Action            |
| -------- | ----------------- |
| q or Esc | Quit to Main Page |
