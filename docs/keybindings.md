# Key bindings

## Universal/App-wide scope

| Key | Action                                        |
| --- | --------------------------------------------- |
| ?   | Open a help box to view available keybindings |

## Home Screen

| Key        | Action                               |
| ---------- | ------------------------------------ |
| ctrl+o     | Choose directory/folder              |
| ctrl+enter | Manage the selected directory/folder |
| q or Esc   | Quit                                 |

## Image Screen

### Main Page

| Key      | Action                                             |
| -------- | -------------------------------------------------- |
| l        | Next photo                                         |
| h        | Previous photo                                     |
| j        | Mark for delete                                    |
| k        | Mark for keep                                      |
| c        | Mark for clear                                     |
| m        | Mark for review                                    |
| o        | Open current image in system's default application |
| e        | Open current image in system's file explorer       |
| q or Esc | Quit to Home screen                                |

### Summary Page

#### Main actions

| Key        | Action                       |
| ---------- | ---------------------------- |
| q or Esc   | Quit to Main Page            |
| ctrl+enter | Enter into confirmation mode |

##### Confirmation prompt

| Key             | Action         |
| --------------- | -------------- |
| q or Esc        | Close prompt   |
| n               | Do not proceed |
| y or ctrl+enter | Proceed        |
