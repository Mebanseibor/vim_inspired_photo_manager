# Key bindings

## Universal/App-wide scope

| Key | Action                                        |
| --- | --------------------------------------------- |
| ?   | Open a help box to view available keybindings |

## Home Screen

| Key        | Action                               |
| ---------- | ------------------------------------ |
| ctrl+o     | Choose directory/folder              |
| ctrl+enter | Manage the selected directory/folder |
| ctrl+R     | Reset application session            |
| q or Esc   | Quit                                 |

## Image Screen

### Main Page

| Key        | Action                                             |
| ---------- | -------------------------------------------------- |
| l          | Next photo                                         |
| h          | Previous photo                                     |
| j          | Mark for delete                                    |
| k          | Mark for keep                                      |
| c          | Mark for clear                                     |
| m          | Mark for review                                    |
| o          | Open current image in system's default application |
| e          | Open current image in system's file explorer       |
| I          | Enter into inspection mode                         |
| ctrl+enter | Load summary page                                  |
| q or Esc   | Quit to Home screen                                |

### Inspection Mode

| Key | Action                       |
| --- | ---------------------------- |
| a   | Pan left                     |
| d   | Pan right                    |
| w   | Pan up                       |
| s   | Pan down                     |
| q   | Zoom out                     |
| e   | Zoom in                      |
| Q   | Zoom out and center          |
| E   | Zoom in and center           |
| f   | Zoom to fit                  |
| F   | Zoom to fit and center       |
| c   | Center view to focused image |
| r   | Reset view                   |
| Esc | Exit inspection mode         |

### Summary Page

#### Main actions

| Key        | Action                       |
| ---------- | ---------------------------- |
| q or Esc   | Quit to Main Page            |
| ctrl+enter | Enter into confirmation mode |

##### Confirmation prompt

| Key             | Action         |
| --------------- | -------------- |
| q or Esc        | Close prompt   |
| n               | Do not proceed |
| y or ctrl+enter | Proceed        |
